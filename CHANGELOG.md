# История изменений

## 0.6.21 — 2026-10-02

- «Открытые проекты» перенесены в самый верх панели, непосредственно над «Избранным». Управление каталогом, поиск и остальные разделы расположены ниже.

## 0.6.20 — 2026-10-02

- Избранные проекты можно переставлять, перетаскивая строку вверх/вниз без дополнительных кнопок. Линия показывает вставку перед или после целевого проекта.
- Порядок сохраняется атомарно в общем индексе и синхронизируется между окнами; скрытые поиском избранные не теряются. Перетаскивание из избранного не перемещает папки на диске.

## 0.6.19 — 2026-10-02

- Текст переключателя вида заменён иконками: часы для перехода к активности, папка для возврата к дереву. Русские подсказки и доступные названия сохранены.
- Между видимыми разделами «Открытые проекты» и «Последние активные проекты» добавлен отступ 10px, чтобы блоки не сливались.

## 0.6.18 — 2026-10-02

- Отметки «Открыт» и «Текущее окно» заменены компактной зелёной точкой без рамки; подсказки и выделение текущего окна сохранены.
- Над деревом добавлен переключатель «По активности / По папкам». Режим активности показывает все проекты без группирующих папок и лимита, включая открытые и избранные, по убыванию последнего использования или изменения файлов.
- Выбор вида сохраняется в состоянии панели. Даты в плоском списке показывают последнюю активность; поиск, открытие и избранное продолжают работать. Переключение использует существующий индекс без нового сканирования диска.

## 0.6.17 — 2026-10-02

- У открытых проектов добавлен индикатор IVOL Code Agent 5: вращающийся значок во время работы и квадрат в состоянии простоя/остановки; ожидание ответа выделено цветом и подсказкой.
- Состояние читается напрямую из экспортируемого объекта установленного агента не чаще раза в 60 секунд, без сетевых запросов и чтения истории чатов. Статусы других окон передаются через существующий реестр окон.
- Адаптер проверен по коду Agent 5 версии 5.17.63 и использует внутренний провайдер экспортируемого объекта. При несовместимости показывается «статус недоступен», без установленного агента индикатор скрыт. Агент принудительно не активируется.
- Для получения статусов во всех локальных окнах нужно перезапустить каждое окно вручную. Интервал обновления допускает задержку около минуты; короткие задачи между опросами могут не отображаться.

## 0.6.16 — 2026-10-02

- Под поиском добавлен раздел «Открытые проекты»: все открытые проекты каталога без лимита и зависимости от давности активности, включая избранные. Текущий проект первый, остальные — по названию.
- «Последние активные проекты» теперь содержит только закрытые проекты с прежним лимитом и сортировкой активности. Избранные по-прежнему не дублируются в последних.
- Поиск работает и в новом разделе; клик переключает существующее окно. Списки обновляются через существующий реестр окон без переиндексации.

## 0.6.15 — 2026-10-01

- Убраны ограничения количества избранных проектов при добавлении, чтении сохранённого списка и синхронизации между окнами.
- Счётчик избранного показывает только количество; подсказки о лимите и освобождении места удалены. Порядок и существующие отметки сохраняются.

## 0.6.14 — 2026-09-30

- Общий постоянный индекс для окон одного профиля: одна начальная индексация, затем загрузка без обхода диска. Полная перестройка только по ↻; внешние изменения ждут ручной переиндексации.
- Атомарная запись, общая межоконная блокировка, подхват ревизии примерно раз в 2 секунды. Корни, правила скрытия, названия и избранное хранятся вместе с индексом.
- Создание, перенос, корзина, скрытие и названия обновляются адресно. Подключение корня/возврат скрытой ветки сканируют только добавленную область.
- Скрытые папки исключаются также из расчёта дат и вспомогательного чтения сканера. После установки нужна одна начальная индексация; все окна следует вручную перезапустить.

## 0.6.13 — 2026-09-30

- Готовый каталог разблокируется сразу после сканирования: синхронизация активности и открытых окон выполняется в фоне, без ожидания перед показом дерева.
- Последние проекты сначала строятся по данным в памяти, затем обновляются после синхронизации. Фоновые ошибки не блокируют каталог; устаревшие завершения не обрабатывают события нового сканирования.
- В журнал «Каталог проектов» добавлены отдельные длительности сканирования, синхронизации активности и окон. Правила обхода и отсутствие автосканирования сохранены; кэш дерева не добавлен.

## 0.6.12 — 2026-09-30

- В дереве, избранном и последних проектах добавлены цветные отметки «Открыт» и «Текущее окно», без дополнительного блока и дублирования списков.
- Клик по открытому локальному проекту переключает существующее окно, по текущему — не создаёт дубликат. Для сохранённых multi-root используется файл рабочей области; несохранённые требуют сохранения.
- Отдельный реестр живых окон обновляется раз в 2 секунды без пересканирования проектов; закрытые/устаревшие окна исключаются из отметок. Все учитываемые окна должны загрузить новую версию расширения.

## 0.6.11 — 2026-09-29

- Убрано периодическое автосканирование: каталог загружается при запуске окна, повторное сканирование — по кнопке ↻. Возвращение в открытую панель не запускает обход.
- Удалена настройка интервала обновления; ранее сохранённое значение больше не используется.
- Изменение настроек не запускает пересканирование: параметры обхода применяются при следующем обновлении, лимит последних проектов — сразу.
- Действия с папками через каталог по-прежнему сразу обновляют список; синхронизация активности между окнами сохраняется без обхода проектов.

## 0.6.10 — 2026-09-29

- Избранные проекты не дублируются в последних активных, даже если проект открыт в текущем окне. Освободившиеся места занимают следующие проекты по активности.
- Добавление и удаление избранного сразу обновляет последние проекты; история активности сохраняется.

## 0.6.9 — 2026-09-29

- Перед скрытием через кнопку строки или контекстное меню появляется подтверждение «Точно скрыть папку?» с названием и путём. Отмена оставляет папку видимой.
- Звёздочка избранного больше не показывается постоянно: появляется вместе с действиями строки при наведении или клавиатурном фокусе.

## 0.6.8 — 2026-09-29

- Блок «Избранное» в самом верху панели, выше управления, поиска и недавних проектов.
- Постоянно видимая звёздочка у каждого проекта: добавить или убрать из избранного, максимум 7 проектов, без автоматического вытеснения.
- Избранное сохраняется между перезапусками, следует за переносом через каталог и фильтруется поиском; исходные проекты остаются в дереве.
- Скрытые и недоступные избранные не показываются, но сохраняют свои места; при заполнении лимита можно явно выбрать, какую запись убрать, в том числе недоступную.

## 0.6.7 — 2026-09-28

- Поиск папок и проектов сверху панели: фильтрация по части названия без учёта регистра при вводе.
- Сохраняются родительские цепочки, найденные ветки автоматически раскрываются; последние активные проекты также фильтруются.
- Очистка крестиком или Escape возвращает обычное дерево с прежними раскрытиями; предусмотрено сообщение при отсутствии совпадений.
- Поиск использует только доступные элементы каталога, не сканирует содержимое файлов и не возвращает скрытые папки.

## 0.6.6 — 2026-09-27

- В контекстное меню дерева добавлены «Скрыть из каталога» и «Удалить в корзину…».
- Корзина используется только после подтверждения пути, без безвозвратного fallback; защищены корни, ссылки и несохранённые файлы текущего окна.
- После удаления дерево обновляется; история и предпочтения сохраняются для восстановления папки.

## 0.6.5 — 2026-09-27

- При сканировании вся панель становится серой и неактивной, поверх неё отображается плашка «Обновление каталога…».
- Блокируются мышь и клавиатурный фокус внутри панели; после завершения или ошибки доступ восстанавливается.

## 0.6.4 — 2026-09-27

- Значок ◎ у вложенных папок с нулём проектов: назначить текущую папку проектом без ввода имени.
- Разделены названия команд назначения существующей папки и создания нового проекта внутри неё.

## 0.6.3 — 2026-09-27

- Новые проекты внутри каталога сразу учитываются как проекты, даже пустые.
- Контекстные команды «Считать проектом» и «Вернуть автоопределение» для существующих папок.
- Явные проекты учитываются в счётчиках и активности; отметка сохраняется при переносе.
- Категории остаются категориями, служебные файлы в проектах не создаются.

## 0.6.2 — 2026-09-27

- Публичное название расширения — IVOL Cataloger.
- Добавлены поисковые ключевые слова ivol и cataloger.
- Основной способ установки в документации — магазин расширений.
- Идентификатор ivol.ivol-project-catalog сохранён: обновление не создаёт отдельное расширение.

## 0.6.1 — 2026-09-27

- Подготовка публичного выпуска: MIT, метаданные репозитория, иконка магазина.
- Документация установки, ограничений переноса и выпуска через GitHub Actions.
- Ограничен состав VSIX: только код, ресурсы, описание, лицензия и история изменений.
- Функциональность каталога сохранена из версии 0.6.0.

## 0.6.0 — 2026-09-27

- Перетаскивание проекта из дерева или недавних в каталог с подтверждением реального переноса.
- Защита от перезаписи, переноса в себя, дочернюю папку и на другой том.
- Перенос собственных предпочтений и активности каталога на новый путь.

## 0.5.0–0.5.2 — 2026-09-27

- Кнопка «Новый проект», пошаговый выбор каталога и открытие нового окна.
- Создание проекта из контекстного меню папки.
- Разделены создание каталога первого уровня и создание проекта внутри него.

## 0.4.0–0.4.12

- Компактная панель: недавние проекты и многоуровневое дерево.
- Выделение текущего проекта, фоновое обновление и локальная история активности.
- Распознавание проектов по IDE/Git, исходникам и файлам сборки.
- Отображаемые названия, скрытие и восстановление, добавление пропущенных и пустых папок.
- Создание каталогов, индикация загрузки, кнопки действий при наведении.

Предыдущие версии распространялись как локальные сборки VSIX.
