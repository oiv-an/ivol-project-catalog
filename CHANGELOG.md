# История изменений

## 0.7.12 — 2026-10-06

- Убраны двойные индикаторы в боковом каталоге: открытый проект показывает один значок состояния агента, а при отсутствии его статуса — отметку открытого окна. Подсказка объединяет оба контекста; системная строка macOS не менялась.

## 0.7.11 — 2026-10-06

- Серое кольцо без выбранной задачи в строке меню увеличено с 6 до 9 пикселей, обводка усилена до 1.6 пикселя. Используется непрозрачный светло-серый цвет, чтобы индикатор не терялся на фоне панели. Размер контейнера, положение полоски и остальные индикаторы сохранены.

## 0.7.10 — 2026-10-06

- Разделены завершённая выбранная задача и отсутствие выбранной задачи: первая отмечается крупной зелёной точкой, второе — серым контурным кольцом в строке меню и каталоге. В многокорневом окне задача относится только к своему проекту.
- Завершение определяется по текущему ожиданию результата Agent 5; ошибки и лимиты в состоянии простоя больше не дают зелёную точку. Размеры, положение полоски и индикатор работы сохранены.

## 0.7.9 — 2026-10-06

- Зелёная точка свободного проекта увеличена с 4 до 9 пикселей. Размер контейнера индикатора и расстояния между названиями сохранены; остальные состояния не менялись.

## 0.7.8 — 2026-10-06

- Статичная точка свободного проекта теперь зелёная: проект открыт, агент без задачи. Работа по-прежнему обозначается зелёным вращающимся индикатором. Неизвестные и неактивные состояния не менялись.

## 0.7.7 — 2026-10-06

- Публичный выпуск принятой версии macOS: единая компактная полоска проектов в строке меню с анимированными статусами агентов. Поведение и внешний вид 0.7.6 сохранены.
- Убрано обещание плавающей панели Windows: это возможная идея без сроков, разработка отложена.

## 0.7.6 — 2026-10-06

- Уплотнена общая полоска: пропорциональный системный шрифт, уменьшенные промежутки; ширина каждого проекта рассчитывается по фактическому названию, лимит букв не резервирует пустое место.
- Вместо квадратных символов нарисованы индикаторы: зелёный вращающийся — работа, оранжевые часы — ожидание ответа, пауза — остановка, нейтральная точка — без задачи, контурный круг — агент не активирован, вопрос — статус недоступен.
- Анимация меняет только иконки без чтения файлов и изменения ширины сегментов; учитывается системное уменьшение движения. Настройка длины подписи и положение полоски сохраняются.

## 0.7.5 — 2026-10-06

- Все открытые проекты объединены в один элемент строки меню macOS: ⌘ + перетаскивание перемещает всю полоску, новые проекты добавляются внутри неё без отдельных системных значков.
- Клик по названию переключает соответствующий проект; правый клик открывает общий список. При переполнении доступен сегмент +N. Отдельной кнопки IVOL нет.

## 0.7.4 — 2026-10-06

- Убрана отдельная кнопка IVOL: в строке меню остаются только открытые проекты. Общий список и выход доступны правым кликом по проекту; при отсутствии проектов значков нет.
- Сохранены пользовательские позиции проектов. В настройках пояснено перемещение через ⌘ + перетаскивание и ограничение macOS: системные значки нельзя перенести в левую область /меню приложения.
- Диагностика помощника теперь относится к кнопкам проектов, а не удалённому служебному значку; отсутствие открытых проектов показывается отдельно.

## 0.7.3 — 2026-10-06

- Устранена зависимость переключателя строки меню от регистрации настроек VS Code: режим и длина подписи сохраняются атомарно в общем хранилище Cataloger. Старые значения читаются только при миграции. Ошибка «not a registered configuration» больше не блокирует этот переключатель.
- В настройках отдельно отображается фактический ответ помощника, число проектов и экран по данным macOS; сохранённое включение не выдаётся за подтверждение видимости кнопок.
- Приложение запускается через LaunchServices. Плагин и помощник используют общий постоянный выбор режима; выход из меню сохраняет выключение, чтобы плагин не запускал приложение снова.

## 0.7.2 — 2026-10-06

- Помощник macOS запускается самостоятельно без аргументов и сразу показывает постоянную кнопку IVOL даже до подключения плагина. В меню видны число подключённых окон и команда завершения.
- Новые кнопки получают начальную позицию справа, чтобы не попадать сразу в скрытую область Hidden Bar. Существующие пользовательские позиции сохраняются, настройки Hidden Bar не меняются.
- Форма настроек получает платформу и текущее включение сразу в HTML; обработчик сообщений регистрируется до загрузки формы. Переключатель больше не зависит от первоначального ответа для разблокировки. Добавлены диагностические сообщения формы и команда палитры «Проекты: Включить / выключить строку меню macOS».
- Включённый плагин подхватывает автономного помощника; выключение передаётся ему отдельной локальной командой. Отсутствие/устаревание данных плагина по-прежнему отслеживается без сканирования проектов.

## 0.7.1 — 2026-10-06

- Переключатель строки меню macOS теперь сразу сохраняет настройку и запускает/выключает помощник, без отдельного «Сохранить настройки». Раньше надпись «Включено» могла означать только несохранённое состояние формы.
- Во время сохранения показывается «Включаю…»/«Выключаю…», повторные нажатия блокируются; после ответа отображается фактическое значение настройки. Ошибка сохранения выводится рядом с переключателем, остальные несохранённые поля не сбрасываются.

## 0.7.0 — 2026-10-06

- macOS: открытые проекты каталога можно вывести отдельными кнопками в системную строку меню. Включение — «Проекты → ⚙ → Проекты в строке меню macOS → Сохранить настройки»; по умолчанию выключено.
- Нативный помощник без значка Dock: короткие названия с различением совпадений, полный путь и статус при наведении, один клик для перехода к папке/сохранённой рабочей области. Общая кнопка ▦ и правый клик открывают полный список как запасной доступ при нехватке места.
- Состояние IVOL Code Agent 5 проверяется примерно раз в 2 секунды при включённой строке меню; без неё сохраняется прежний интервал 60 секунд. Устаревшие и неизвестные данные отмечены отдельно.
- Один помощник на общее хранилище окон; закрытие окна-инициатора не убирает кнопки остальных проектов. После закрытия всех включённых окон помощник завершается. Повторный запуск защищён межпроцессной блокировкой.
- В пакет включён универсальный помощник для Apple Silicon и Intel, macOS 14+. Сборка пакета теперь требует macOS и Apple Command Line Tools; установленное расширение не требует компилятора. Плавающая панель и поддержка системного доступа Windows — следующий этап.
- Для появления всех проектов и актуальных статусов вручную перезапустите каждое нужное окно VS Code. Удалённые окна и несохранённые рабочие области не поддерживаются; одинаковый проект в нескольких окнах представлен одной кнопкой.

- Между видимыми разделами «Открытые проекты» и «Последние активные проекты» добавлен отступ 10px, чтобы блоки не сливались.

## 0.6.18 — 2026-10-02

- Выбор вида сохраняется в состоянии панели. Даты в плоском списке показывают последнюю активность; поиск, открытие и избранное продолжают работать. Переключение использует существующий индекс без нового сканирования диска.

## 0.6.17 — 2026-10-02

- У открытых проектов добавлен индикатор IVOL Code Agent 5: вращающийся значок во время работы и квадрат в состоянии простоя/остановки; ожидание ответа выделено цветом и подсказкой.
- Состояние читается напрямую из экспортируемого объекта установленного агента не чаще раза в 60 секунд, без сетевых запросов и чтения истории чатов. Статусы других окон передаются через существующий реестр окон.
- Адаптер проверен по коду Agent 5 версии 5.17.63 и использует внутренний провайдер экспортируемого объекта. При несовместимости показывается «статус недоступен», без установленного агента индикатор скрыт. Агент принудительно не активируется.
- Для получения статусов во всех локальных окнах нужно перезапустить каждое окно вручную. Интервал обновления допускает задержку около минуты; короткие задачи между опросами могут не отображаться.

## 0.6.16 — 2026-10-02

- Под поиском добавлен раздел «Открытые проекты»: все открытые проекты каталога без лимита и зависимости от давности активности, включая избранные. Текущий проект первый, остальные — по названию.
- «Последние активные проекты» теперь содержит только закрытые проекты с прежним лимитом и сортировкой активности. Избранные по-прежнему не дублируются в последних.
- Поиск работает и в новом разделе; клик переключает существующее окно. Списки обновляются через существующий реестр окон без переиндексации.

## 0.6.15 — 2026-10-01

- Убраны ограничения количества избранных проектов при добавлении, чтении сохранённого списка и синхронизации между окнами.
- Счётчик избранного показывает только количество; подсказки о лимите и освобождении места удалены. Порядок и существующие отметки сохраняются.

## 0.6.14 — 2026-09-30

- Общий постоянный индекс для окон одного профиля: одна начальная индексация, затем загрузка без обхода диска. Полная перестройка только по ↻; внешние изменения ждут ручной переиндексации.
- Атомарная запись, общая межоконная блокировка, подхват ревизии примерно раз в 2 секунды. Корни, правила скрытия, названия и избранное хранятся вместе с индексом.
- Создание, перенос, корзина, скрытие и названия обновляются адресно. Подключение корня/возврат скрытой ветки сканируют только добавленную область.
- Скрытые папки исключаются также из расчёта дат и вспомогательного чтения сканера. После установки нужна одна начальная индексация; все окна следует вручную перезапустить.

## 0.6.13 — 2026-09-30

- Готовый каталог разблокируется сразу после сканирования: синхронизация активности и открытых окон выполняется в фоне, без ожидания перед показом дерева.
- Последние проекты сначала строятся по данным в памяти, затем обновляются после синхронизации. Фоновые ошибки не блокируют каталог; устаревшие завершения не обрабатывают события нового сканирования.
- В журнал «Каталог проектов» добавлены отдельные длительности сканирования, синхронизации активности и окон. Правила обхода и отсутствие автосканирования сохранены; кэш дерева не добавлен.

## 0.6.12 — 2026-09-30

- В дереве, избранном и последних проектах добавлены цветные отметки «Открыт» и «Текущее окно», без дополнительного блока и дублирования списков.
- Клик по открытому локальному проекту переключает существующее окно, по текущему — не создаёт дубликат. Для сохранённых multi-root используется файл рабочей области; несохранённые требуют сохранения.
- Отдельный реестр живых окон обновляется раз в 2 секунды без пересканирования проектов; закрытые/устаревшие окна исключаются из отметок. Все учитываемые окна должны загрузить новую версию расширения.

## 0.6.11 — 2026-09-29

- Удалена настройка интервала обновления; ранее сохранённое значение больше не используется.
- Изменение настроек не запускает пересканирование: параметры обхода применяются при следующем обновлении, лимит последних проектов — сразу.
- Действия с папками через каталог по-прежнему сразу обновляют список; синхронизация активности между окнами сохраняется без обхода проектов.

- Добавление и удаление избранного сразу обновляет последние проекты; история активности сохраняется.

## 0.6.1 — 2026-09-27

- Подготовка публичного выпуска: MIT, метаданные репозитория, иконка магазина.
- Документация установки, ограничений переноса и выпуска через GitHub Actions.
- Ограничен состав VSIX: только код, ресурсы, описание, лицензия и история изменений.
- Функциональность каталога сохранена из версии 0.6.0.

## 0.6.0 — 2026-09-27

- Перетаскивание проекта из дерева или недавних в каталог с подтверждением реального переноса.
- Защита от перезаписи, переноса в себя, дочернюю папку и на другой том.
- Перенос собственных предпочтений и активности каталога на новый путь.

## 0.5.0–0.5.2 — 2026-09-27

- Кнопка «Новый проект», пошаговый выбор каталога и открытие нового окна.
- Создание проекта из контекстного меню папки.
- Разделены создание каталога первого уровня и создание проекта внутри него.

## 0.4.0–0.4.12

- Компактная панель: недавние проекты и многоуровневое дерево.
- Выделение текущего проекта, фоновое обновление и локальная история активности.
- Распознавание проектов по IDE/Git, исходникам и файлам сборки.
- Отображаемые названия, скрытие и восстановление, добавление пропущенных и пустых папок.
- Создание каталогов, индикация загрузки, кнопки действий при наведении.

Предыдущие версии распространялись как локальные сборки VSIX.
