# Открытые проекты VS Code — прямо в строке меню macOS

Работаю сразу в нескольких проектах. В одном агент пишет код, в другом ждёт ответа, в третьем уже закончил. Чтобы переключиться, раньше приходилось сначала искать нужное окно VS Code.

В IVOL Cataloger добавил более короткий путь: **единую полоску открытых проектов в верхней строке меню macOS**. Нажимаешь на название — переходишь в нужное окно. Рядом видно состояние агента.

Функция доступна в версии **0.7.11**. Это не отдельный рабочий стол и не ещё один список задач: просто быстрый доступ к уже открытым проектам.

## Что показывает полоска

Открытые проекты каталога появляются в системной строке меню. Закрытые окна исчезают из списка. Один проект, открытый в нескольких окнах, не дублируется.

Названия можно сократить до 2–12 букв. Короткие подписи занимают ровно столько места, сколько нужно; одинаковые начала различаются дополнительными символами. При наведении доступны полное название и путь.

Рядом с проектом — индикатор IVOL Code Agent 5:

- **Зелёный вращающийся индикатор:** агент работает.
- **Крупная зелёная точка:** выбранная задача завершена по состоянию агента.
- **Серое кольцо:** задача не выбрана или расширение агента ещё не активировано.
- **Оранжевые часы:** агент ждёт ответа или подтверждения.
- **Пауза:** работа остановлена.
- **Нейтральная точка:** задача открыта, но завершение не подтверждено.
- **Вопросительный знак:** состояние недоступно или устарело.

Важная деталь: «ничего не выполняется» и «задача завершена» — разные состояния. Ошибка, лимит или просто пустое окно не должны зажигать зелёную точку. При этом завершение по данным агента не заменяет проверку результата человеком.

## Как включить

1. Установите или обновите **IVOL Cataloger**.
2. После обновления вручную перезапустите нужные окна VS Code, чтобы они передавали актуальные состояния.
3. Откройте **«Проекты»** в левой панели. Если каталог ещё пустой, нажмите **＋** и добавьте папку с проектами.
4. Нажмите **⚙** и включите **«Проекты в строке меню macOS»**.
5. При необходимости настройте длину названий.

По умолчанию функция выключена. Изменение настройки применяется сразу.

**Клик по названию** переключает проект. **Правый клик** открывает общий список и пункт выхода. **⌘ + перетаскивание** перемещает всю полоску как один элемент, положение сохраняется. Если места не хватает, появляется **+N** со списком остальных проектов.

## Новый проект из строки меню (0.7.16)

**＋ → Куда → Название → Enter** — пустая папка создаётся и сразу открывается в новом окне VS Code. Форма выпадает прямо из строки меню, без переключения в старое окно редактора.

В «Куда» доступны каталоги и вложенные группы, отсортированные по активности, а также выбор другой папки на диске. Создание внутри подключённого каталога сразу назначает папку проектом; вне каталога папка только открывается. Корень каталога нельзя выбрать родителем проекта. Существующие папки не перезаписываются. Плюс остаётся виден даже без открытых проектов.

После обновления перезапустите окно VS Code, затем выключите и включите строку меню в настройках: уже работающий помощник должен загрузиться из новой версии.

## Что пришлось довести

Сначала отдельные значки было неудобно перемещать. Поэтому проекты собраны в одну полоску, без дополнительной кнопки с названием расширения.

Затем убрал лишние промежутки и сделал ширину подписей зависимой от текста. Индикатор работы анимируется, а завершённая задача обозначается статичной точкой — их можно различить с первого взгляда.

Последняя правка оказалась совсем небольшой, но заметной: серое кольцо терялось на фоне обоев. Увеличил его до 9 пикселей, усилил обводку и сделал цвет непрозрачным. Зелёная точка тоже размером 9 пикселей.

## Как устроено и какие ограничения

Системную строку рисует небольшой нативный помощник на Swift/AppKit. Расширения в окнах передают ему данные через локальное хранилище; один помощник обслуживает все подключённые окна. Готовое приложение входит в пакет — отдельно устанавливать компилятор не нужно.

Исходники: [MenuBar.swift](../native/macos/MenuBar.swift), [agent-status.js](../src/agent-status.js), [desktop.js](../src/desktop.js).

- Строка меню работает на **macOS 14+**, Apple Silicon и Intel. Windows-панели в этом выпуске нет.
- Показываются локальные проекты одного редактора и профиля. Удалённые окна не поддерживаются.
- Статусы интегрированы именно с **IVOL Code Agent 5**. История чатов не читается, для получения статусов не нужны сетевые запросы.
- При включённой полоске состояние опрашивается примерно каждые 2 секунды, поэтому возможна небольшая задержка.
- Видимость подчиняется настройкам строки меню macOS. Если её скрывает система или Hidden Bar, нужно открыть строку либо переместить полоску в видимую область.
